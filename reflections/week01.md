Task 2 — Applying the Four Process Activities

Stage 1 - KickOff
The specification for this stage was thee but it was weak. An hour long meeting was held with the developer with a brief explanation of what was needed . No requirements were gathered and wrote out. The warehouse staff were also not consulted.

Stage 2 - Development
The development was also weak. The developers did not work work together and had no coding standards and code reviews

Stage 3 - A Change of Plan 
This was also weak. the company introduced a new requirement for a second warehouse. the developers did the not review the original system. This caused issues because because the second warehouse used a different shelving and barcode system.  

Stage 4 - Testing
The validation of the system was weak. The developers tested the system themselves for 2 days. There was no test cases. The developers also did not include the warehouse in the testing so this means there was no user testing which would have been helpful.

Stage 5 - Go live
Major problems were discovered by warehouse staff after the system went live, forcing the developers to make more changes.

The biggest Issue in the development for me was the requirements were not fully gathered. The developers did not know fully what the warehouse staff needed which caused problems later on in the development.
