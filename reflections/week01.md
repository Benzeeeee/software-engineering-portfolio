software is a set of instructions that tells the computer, devices or applications what to do, it helps interact with devices that were never possible. For example you can use software to make music, play games and edit videos. Engineering for software development gives structure, reliability, scalability and systematic methods to software. For the structure aspect it adds the ability to create a step-by-step process to plan design, test and maintain to prevent the possibility of project failure. Reliability is important to reduce the risk of the software crashing in real-world stress. To achieve this testing, debugging and error handling must be implemented. Scalability is important to handle growth in users, data and traffic. Software that has worked well for me has been You Tube or VS code. software that hasn't worked well for me would be Windows. A frustrating part of using windows is that it will run slow when there are a few processes running at the same time. i think the developers could fix this by managing the background processes so that they don't take up as much of the CPU.
